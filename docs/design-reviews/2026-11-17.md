## Findings

| Finding | Severity | Evidence and disposition |
|---|---|---|
| Offline reload failed although records were saved | Major, fixed | Production worker previously cached nothing. Enabled lifecycle regression now reloads two records offline, writes a third and reloads again. |
| Clear demo could appear successful before deletion committed | Major, fixed | Reload produced five records instead of two. UI now waits for deletion; delayed-storage regression and all 23 browser tests pass. |
| First-load layout shift and missing favicon | Minor, fixed | Reserved loading height, font preloads and favicon added. Latest Lighthouse reports CLS 0 and best practices 100 in both presets. |
| Long titles are heavily truncated on scene objects | Minor, remaining | The demo titles become short fragments on plates. Full titles are available in the matching text list and detail dialogs. This is still the weakest visual decision for identifying similar deadlines. |
| Mobile scene sits below a tall toolbar and two invitations | Minor, remaining | 390 px screenshot shows the content hierarchy. Toolbar wraps without page overflow; list-only mode is available immediately. Scene itself intentionally scrolls horizontally. A future compact toolbar should be reviewed with users rather than silently replacing the agreed layout. |
| Kiro custom-agent invocation missing | Evidence gap | This manual review does not complete the Kiro design-review task. |
